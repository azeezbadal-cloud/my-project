# Wagga Wagga Community Care – cinematic promo video

A 23-second vertical (1080 × 1920) promotional video built with **Remotion (React + TypeScript)** and **FFmpeg**.
Your original footage stays the star – everything else (glass banners, animated service cards, Australia map,
logo reveal, light trails, music and sound effects) is generated by code, so every word, timing and colour can be changed
in one file and re-rendered.

```
00:00  Welcome            glass banner sweeps in → WELCOME TO OUR COMMUNITY → WAGGA WAGGA COMMUNITY CARE
00:03  Announcement       WE'RE NOW OPEN!  (green/blue glowing glass + sparkle)
00:06  Services           SUPPORT THAT MAKES A DIFFERENCE → 7 animated service cards with icons
00:14  Expansion          map: STARTING IN WAGGA WAGGA → OUR NEXT CHAPTER → Toowoomba · Newcastle · Sydney · Coffs Harbour (Planned Expansion)
00:19  Ending             your logo reveal → YOUR GOALS. OUR SUPPORT. → ENQUIRE TODAY
```

## Quick start

**You need:** Node.js 18+ (tested on 22), FFmpeg on your PATH, and – only for the optional speaker cut-out – Python 3.10+
with `pip install onnxruntime numpy pillow` (about 6 GB of free RAM while it runs).

```bash
npm install
```

1. Put your original video at `assets/original/video.mov`
2. Prepare it (conform to 1080×1920 @ 30 fps, un-mirror, colour grade, extract the voice track):

   ```bash
   npm run prep:footage
   ```
3. *(Optional, slow – a few seconds per frame)* cut the presenter out of the background so light trails and glass sit **behind** you:

   ```bash
   npm run prep:matte
   ```
   Skip it and set `useSpeakerCutout: false` in `src/config.ts` – the video still renders, just without the depth layering.
4. Preview and edit live in the browser:

   ```bash
   npm run studio
   ```
5. Render the finished video (picture → sound → mux):

   ```bash
   npm run render
   ```
   Result: `out/WWCC-promo-1080x1920.mp4` (H.264 + AAC, ‑14 LUFS, true-peak ‑1 dB).

Handy extras:

| command | what it does |
| --- | --- |
| `npm run stills -- 3.5 8 15.2` | renders PNG frames at those seconds into `out/stills/` for a quick look |
| `npm run audio` | rebuilds only the music / effects / voice mix → `out/audio-mix.wav` |
| `npm run render:video` | rebuilds only the picture → `out/video-silent.mp4` |
| `npm run build:map` | regenerates the map dots/coastline (only needed if you change the map style) |
| `npm run typecheck` | TypeScript check |

## What you can edit – `src/config.ts`

Everything editable is in this one file:

* **Text** – every headline, sub-line, service name (`lines` = your own line breaks), CTA, tagline.
* **Timings** – `start` / `end` of each scene (seconds), service heading length, city reveal start + step.
* **Services** – name, icon (any `lucide` icon registered in `src/components/Icon.tsx`) and accent colour.
* **Expansion cities** – name, latitude / longitude, which side the label sits on.
* **Colours / fonts** – brand palette (sampled from your logo) and the two fonts (Montserrat + Manrope).
* **Contact details** – `outro.contact = {website, phone, email, qrImage}`. **Nothing is shown unless you fill it in** –
  no website, phone number or QR code is ever invented. (`qrImage` is a file inside `public/`.)
* **Safe areas** – `safe` keeps text clear of the Instagram / Facebook Reels and TikTok interface.

Sound-effect timing follows the animation timing automatically (both read `src/timeline.ts`).

## How it is built

```
original.mov ──prep:footage──► public/footage.mp4 (graded) + assets/work/voice_raw.wav
             ──prep:matte────► public/fg.webm  (presenter with transparency – BiRefNet-lite)
src/ (Remotion) ──render:video─► out/video-silent.mp4
scripts/make-audio.ts ──audio──► out/audio-mix.wav
                         mux  ──► out/WWCC-promo-1080x1920.mp4
```

Layer order, bottom → top: blurred fill → graded footage → light streaks / particles → glass banners →
presenter cut-out (sharp, soft blue rim light) → map & logo stage → finishing overlay.
From the map onward the footage shrinks into a floating window so the map and logo have room without ever
covering your face, hands or brochure.

```
src/config.ts          ← edit this
src/timeline.ts        scene-internal timings + sound-effect cue sheet
src/scenes/            Welcome · NowOpen · Services · Expansion · Outro
src/components/        Glass, SplitText (letter reveals), Atmosphere (streaks/particles), AuMap, Icon, VideoStage …
scripts/               prepare-footage.sh · make_matte.py · assemble_matte.py · make-audio.ts · build-map-data.mjs · mux.sh
public/logo.png        your supplied logo (used as-is)
```

## Sound design

Everything is synthesised by `scripts/make-audio.ts`, so there are **no licensing issues**:
a warm 100 BPM D-major music bed (pad, soft plucks, bass, gentle percussion) whose big hit lands exactly on the logo reveal,
plus glass slides, light whooshes, icon pulses, location-marker impacts, sparkles and a logo-reveal sound.
Your voice is cleaned (high-pass, light denoise, presence EQ, gentle compression), the music ducks under it, and the
final mix is loudness-normalised to the social-media standard.

## Notes

* **Mirrored footage:** phone selfie video is usually saved mirrored, which made the brochure and wall poster read
  backwards. `prep:footage` un-mirrors it. To keep it exactly as shot: `FLIP=0 npm run prep:footage` (and
  `python3 scripts/assemble_matte.py --flip 0`).
* **NDIS:** nothing in this video uses the NDIS logo or claims NDIS registration.
* **Large media is git-ignored** (`assets/`, `public/footage.mp4`, `public/fg.webm`, `out/`) because it contains people
  and is big. Keep your original footage out of public repositories.
* **Chrome:** Remotion downloads its own headless Chrome on first use. If that is blocked, point it at an installed
  Chrome/Chromium: `REMOTION_BROWSER=/path/to/chrome npm run stills -- 5` or add
  `--browser-executable=/path/to/chrome` to the `remotion` commands.
* **Licences of the pieces used:** Remotion (see <https://www.remotion.dev/license> – free for individuals and small
  teams, other companies may need a paid licence), Montserrat & Manrope fonts (SIL OFL), Lucide icons (ISC),
  Natural Earth map data (public domain), BiRefNet-lite cut-out model (MIT). Music and sound effects are generated here.
