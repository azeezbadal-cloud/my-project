# assets/

Local media that is **not** committed to git (see `.gitignore`):

| path | what goes there |
| --- | --- |
| `assets/original/video.mov` | your original footage (any resolution / frame rate – `npm run prep:footage` conforms it) |
| `assets/work/` | generated intermediates (cut-out frames, audio stems, models) – safe to delete |

Only this README is tracked, so the folder exists after a fresh clone.
